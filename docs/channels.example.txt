# channels.txt: YouTube channels for Crate Digger's SEARCH.
# Put this file in the engine folder, next to bin/ (for example /sdcard/vst/cratedigger/channels.txt).
#
# decade = channel link, @handle, UC... ID or playlist link | name shown on screen (optional)
#
# The left side is a value of the DECADE stepper ("any" is the blank setting). When DECADE is on a
# listed value, SEARCH returns random uploads from that channel. Every other value digs Discogs.
#
#2020s = https://www.youtube.com/@yourchannel | Your Channel
#2010s = @anotherchannel
#any = UCxxxxxxxxxxxxxxxxxxxxxx | Some Channel
